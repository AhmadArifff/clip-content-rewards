# Case-Bank Pola Terverifikasi (`.agents/04-case-bank/cases/`)

Direktori ini menyimpan pola solusi teknis dan arsitektur yang telah teruji di proyek `clip-content-rewards` dalam format YAML terstruktur (`case-YYYYMMDD-<slug>.yaml`).

## Aturan Promosi Status
- Status awal entri baru: `hypothesis`.
- Entri hanya boleh dinaikkan menjadi `verified_case` apabila fitur terkait telah berstatus `done` dan lolos verifikasi independen minimal dari **QA** dan **Tech Critic**.
